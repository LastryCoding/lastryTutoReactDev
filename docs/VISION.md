# Vision produit

## Promesse

React Quest permet a une personne debutante de passer de petits exercices guides
a une mini-application React complete, sans compte et sans installation locale.
Chaque niveau produit un resultat visible, verifiable et reutilisable.

## Probleme resolu

Les ressources pour debuter melangent souvent theorie longue, outils complexes
et exercices sans retour pedagogique. React Quest concentre l'apprentissage sur
les gestes quotidiens d'un projet React professionnel : lire une erreur, typer
une donnee, extraire un composant, gerer un state, tester une interaction et
synchroniser une ressource externe.

## Public

- personnes debutant en TypeScript et React ;
- personnes ayant deja vu JavaScript mais manquant de pratique structuree ;
- apprenants autonomes utilisant un ordinateur avec Chrome ou Edge recent.

L'IDE mobile n'est pas presente comme equivalent a l'experience desktop. Le
tableau de bord et les cours restent consultables sur petit ecran.

## Experience recherchee

- progression claire par mondes et niveaux ;
- sessions courtes de 10 a 20 minutes ;
- code de depart guide puis autonomie croissante ;
- retour immediat, pedagogique et actionnable ;
- recompenses legeres : XP, badges, progression et animation courte ;
- aucune punition lors d'une erreur ;
- reprise exacte apres fermeture ou rechargement de la page.

## Principes non negociables

1. Le code des visiteurs s'execute uniquement dans leur navigateur.
2. La progression ne quitte jamais leur navigateur.
3. Une validation repose sur des preuves deterministes, pas sur l'absence d'erreur.
4. Aucun bouton ne doit simuler une fonctionnalite.
5. Aucun exercice livre ne doit etre vide, fictif ou incomplet.
6. Une fonctionnalite n'est annoncee comme terminee qu'apres verification.
7. KISS prime : la solution correcte la plus simple est preferee.

## Non-objectifs V1

- authentification ou synchronisation cloud ;
- backend applicatif ou base de donnees ;
- collaboration temps reel ;
- execution distante de code ;
- support complet de tous les navigateurs et appareils mobiles ;
- enseignement des types TypeScript avances ou des composants de classe ;
- certification professionnelle officielle.

## Definition de la V1

La V1 comprend 44 exercices principaux, un dashboard complet, un IDE fonctionnel,
une progression locale exportable, des validations pedagogiques, une qualite
automatisee et une image statique deployable derriere Caddy. Les exercices bonus
peuvent etre livres progressivement sans bloquer l'achevement principal.

## Mesure de reussite sans tracking

Le projet n'embarque aucune analytics. La qualite se mesure par les tests
automatises, la validation du contenu, les retours volontaires via GitHub et la
capacite d'un testeur a terminer le parcours critique en navigation privee.
