# Votre premiere mission

Le composant affiche deja une carte de bienvenue. Modifiez son texte pour faire
apparaitre **Bienvenue dans React Quest !**, puis observez le resultat a droite.

## Objectif

Remplacer le texte du titre dans `src/App.tsx` sans changer la structure du
composant.

## Etapes

1. Ouvrez `src/App.tsx`.
2. Reperez le commentaire `TODO 1`.
3. Remplacez le texte du titre.
4. Enregistrez puis observez la previsualisation.

:::tip
Le texte visible entre `<h1>` et `</h1>` est du contenu JSX.
:::

## Resultat attendu

Une carte sombre portant le titre « Bienvenue dans React Quest ! » et un court
message de confirmation.
